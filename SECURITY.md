# Security

*Miden is currently in public testnet. Private reports help us fix security issues before mainnet launch.*

To report a **security** issue affecting Miden, please use the GitHub Security Advisory ["Report a Vulnerability"](security/advisories/new) tab. Our security team will triage the issue and decide on the next steps. We will keep you informed of the progress, and may ask for additional information or guidance.

Non-security issues (performance, usability, etc.) should be reported as a GitHub issue in the appropriate repository.

Thank you for helping keep Miden secure.
